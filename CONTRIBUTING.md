# Contributing Guidelines

We welcome contributions to this open-source project maintained by SPManchester Private Limited.

## Core Guidelines
1. Zero External Dependencies: All conversion routines must execute using vanilla JavaScript and native browser APIs.
2. Complete Client Privacy: No external API calls or tracking scripts are permitted.
3. Code Quality: Ensure cross-browser compatibility across modern browsers.

## Pull Request Process
1. Fork the repository.
2. Create your feature branch (`git checkout -b feature/improvement`).
3. Commit changes with clear messages.
4. Submit your PR with a description of the updates.

For questions, contact info@spmanchester.com.
